# Madarkaci Model School Management System

A modern, web-based school management dashboard designed for **Madarkaci Model School**. This system helps manage student records, staff, examination results, fees, and reports with role-based access control.

## ✨ Features
- **Branded Interface:** Custom dashboard colors matching the school logo.
- **Role-Based Access:** 
  - **Administrator:** Full system access.
  - **Teacher:** Restricted to score entry, attendance, and specific class reports.
  - **Parent/Student:** Access to check results and fee status.
- **Examination Management:** Automatic grade calculation and broadsheet generation.
- **Reporting:** Professional report cards with school headers and digital verification QR codes.
- **Finance:** Track fee payments and outstanding balances.

## 🚀 Getting Started
1. Clone the repository.
2. Open `index.html` in your browser to access the portal.
3. Use the demo credentials provided in the login page hint.

## 🛠️ Technology Stack
- HTML5 & CSS3 (Custom Variables)
- JavaScript (Vanilla ES6)
- SQLite/MongoDB compatible data structures
